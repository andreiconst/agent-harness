## Problem

separability correctly for nested CompoundModels. When a CompoundModel was used as 
part of another CompoundModel (e.g., `Pix2Sky_TAN() & (Linear1D() & Linear1D())`), 
the separability information from the nested model was lost.

## Root Cause
In the `_cstack` function (line 245 of `separable.py`), when the `right` parameter

the code was incorrectly setting the right portion of the output matrix to `1` 
instead of copying the actual `right` array values.
